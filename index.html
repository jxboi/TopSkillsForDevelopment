How to use a skill

A skill is a set of instructions that teaches your coding agent a repeatable way of working. Install one from its repository, then ask your agent for it by name or paste an example prompt from the card's Inside list.

Each card's Works with and Install lines come from the repository's own documentation. Some commands set up a tool first, and some repositories state no single command, so follow the README for the next step.
