Top Skills for Development

The 10 most popular agent skills for software development, and how to use each one.

01WorkflowIntermediate

Superpowers

A comprehensive library of proven techniques, patterns, and tools that give a coding agent a stronger, more reliable workflow.

Best for: General development workflows, from planning to shipping.

How to use it
  1. Install it as a skill or plugin in your coding agent.
  2. Start a task with a clear goal and the files or area in scope.
  3. Let the skill guide planning, implementation, and checks — don't skip its review steps.
  4. Keep the parts that fit your project and drop the rest.

Example prompt

Use the Superpowers workflow to plan, implement, and verify a small feature, with tests and a review at the end.
02WorkflowAdvanced

ECC

An agent-harness optimisation system with skills, memory, security practices, and research-first workflows.

Best for: Teams and long-running agent setups that need consistency and safety.

How to use it
  1. Set it up as your agent's harness, not as a one-off prompt.
  2. Research first: gather docs and codebase context before writing code.
  3. Use its memory and security practices across sessions.
  4. Review agent changes against its checks before merging.

Example prompt

Research this codebase first, then propose a safe, minimal change following the ECC workflow.
03QualityBeginner

Karpathy Skills

A single behaviour guide distilled from common LLM coding pitfalls, helping agents avoid the mistakes developers see most.

Best for: Avoiding overcomplicated, untested, or assumption-heavy agent output.

How to use it
  1. Add the guide to your agent's instructions or project guidance.
  2. Ask the agent to keep changes small and explain its assumptions.
  3. Require tests or a manual check for anything non-trivial.
  4. When output looks too clever, ask for the simpler version.

Example prompt

Follow the Karpathy guidance: keep this change simple, state your assumptions, and verify it before finishing.
04WorkflowIntermediate

Matt Pocock Skills

Skills for real engineers, including alignment interviews that clarify a plan before code, and disciplined test-driven loops.

Best for: Getting the right thing built, not just something that compiles.

How to use it
  1. Start with an alignment step: let the agent interview you about the plan.
  2. Resolve edge cases and trade-offs before implementation.
  3. Use the TDD loop: failing test, minimal code, refactor.
  4. Review the result against the original intent, not just the tests.

Example prompt

Interview me about this design until every open question is resolved, then build it test-first.
05DesignIntermediate

UI/UX Pro Max

Design intelligence for building professional, polished user interfaces across platforms.

Best for: Turning a functional prototype into an interface people enjoy using.

How to use it
  1. Share the product goal, audience, and any brand or style constraints.
  2. Ask for layout, hierarchy, and spacing decisions, not just colours.
  3. Check the result on mobile and desktop widths.
  4. Refine accessibility: contrast, focus states, and readable type.

Example prompt

Redesign this page with professional UI/UX: clear hierarchy, generous spacing, and a mobile-first layout.
06EfficiencyBeginner

Caveman

A concise, token-efficient way for agents to communicate, cutting verbose output while keeping technical accuracy.

Best for: Long sessions, large codebases, and keeping costs and context down.

How to use it
  1. Enable it for sessions where brevity matters more than explanation.
  2. Ask for short, direct summaries of each change.
  3. Request detail only when you need to dig into a decision.
  4. Turn it off for teaching, docs, or stakeholder-facing output.

Example prompt

Work concisely: short summaries only, no extra explanation unless I ask for detail.
07KnowledgeIntermediate

Graphify

Turns a codebase into an explorable knowledge graph, so you can see how modules, data, and features connect.

Best for: Onboarding, refactoring, and understanding unfamiliar code.

How to use it
  1. Point it at the repository or folder you want to understand.
  2. Explore the graph from the feature or module you care about.
  3. Follow connections to find dependencies and side effects.
  4. Use what you learn to scope a change before writing code.

Example prompt

Map this codebase as a knowledge graph and show how the checkout flow connects to payments and orders.
08QualityAdvanced

Agent Skills

Production-grade engineering skills for AI coding agents, focused on reliable, maintainable, real-world code.

Best for: Production work where correctness and maintainability matter most.

How to use it
  1. Choose the skill that matches the task: review, testing, migration, or architecture.
  2. Give it the repo context and the definition of done.
  3. Let it enforce checks, then review its diff like a teammate's PR.
  4. Keep successful patterns as project guidance for next time.

Example prompt

Apply production-grade engineering skills to this change: tests, edge cases, and a careful review.
09KnowledgeIntermediate

Understand-Anything

Turns any codebase into an interactive knowledge graph you can explore, search, and ask questions about.

Best for: Asking “how does this work?” and getting grounded, explorable answers.

How to use it
  1. Load the codebase you want to explore.
  2. Ask a specific question, not just “explain everything”.
  3. Follow the graph to the relevant files and functions.
  4. Verify the answer in the code before acting on it.

Example prompt

Using this codebase's knowledge graph, explain how user authentication works, file by file.
10DiscoveryBeginner

Agentic Awesome Skills

A large catalog of agentic skills, with tools for discovering, comparing, and planning which skills to use.

Best for: Finding the right skill for a new kind of task.

How to use it
  1. Search the catalog by task, not by tool name.
  2. Shortlist two or three skills that fit your workflow.
  3. Try one on a small, real task before adopting it widely.
  4. Keep a short personal list of the skills you actually reuse.

Example prompt

Find the best agent skills for code review and testing, and compare them for a small TypeScript project.
