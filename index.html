A comprehensive library of proven techniques for a stronger, more reliable coding agent workflow.

Poteto's official Cursor plugin that turns Cursor into a real engineering team, helping you write less but higher quality code with rigorous engineering principles and fearless parallelism via /poteto-mode and its 23 playbooks.

Use when At the start of a demanding task such as reproducing defects, tracing performance bottlenecks, or overnight autonomous work needing empirical verification.

Inside this repo — 5 of 23 playbooks
  • bug-fix — Mandates reproducing a reported defect directly on the matching target surface first, binary-searching root causes with runtime evidence, and staging a failing repro test commit before landing the fix.
  • feature — Orchestrates implementing new or modified behavior by establishing domain data shapes, conducting parallel architectural exploration, writing a four-dimension throughput checkpoint, and delegating scoped implementation.
  • investigation — Executes read-only inquiry into how a subsystem functions or why an architectural decision was made, producing cited explanations and tradeoff matrices without introducing code modifications.
  • refactoring — Performs behavior-preserving structural alterations by first pinning existing contracts with characterization tests, eliminating dead code, and migrating callers and legacy APIs simultaneously in a single wave.
