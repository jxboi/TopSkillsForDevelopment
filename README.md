# Top Skills for Development

A beautiful, elegant, static web app listing the top 10 popular agent skills for software development and how to use each one.

## Skills included

1. Superpowers
2. ECC
3. Karpathy Skills
4. Matt Pocock Skills
5. UI/UX Pro Max
6. Caveman
7. Graphify
8. Agent Skills
9. Understand-Anything
10. Agentic Awesome Skills

Each card includes a summary, best use, difficulty, concrete how-to steps, and a copyable example prompt. Use the search box and category filters to explore.

## Run locally

Open `index.html` in a browser. There is no build step and no framework.

## Deploy

This is a static site. Any static host, including Vercel, can serve it directly from the repository root.

> Popularity is indicative from community listings and changes over time; check each skill's own repo for install instructions.
