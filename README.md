# Top Skills for Development

An elegant, responsive field guide to exactly 10 popular development agent skills, in the curated order: Superpowers, ECC, Karpathy Skills, Matt Pocock Skills, UI/UX Pro Max, Caveman, Graphify, Agent Skills, Understand-Anything, and Agentic Awesome Skills.

Each card includes a description, category, difficulty, best use, expandable steps, a copyable example prompt, its original GitHub repository, and an exact star count. Repository links and star counts use the supplied snapshot dated **29 October 2026**; counts are static and do not refresh automatically. Consult each repository for current installation instructions.

Search across the cards and combine the query with category filters. The results count updates immediately, with a reset option when no skills match. Native disclosure controls, keyboard focus states, reduced-motion support, and clipboard fallback are included.

Open `index.html` directly, or serve this folder with any static server (for example, `python3 -m http.server 8000`). There is no build step, framework, external dependency, remote font, or API request. All 10 cards remain readable without JavaScript; search, filters, and copying require it.

Files: `index.html` (content), `styles.css` (design and responsive layout), and `script.js` (search, filters, and copying).
